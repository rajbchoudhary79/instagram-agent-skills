# Rewrite guide

## Order of operations

1. Meaning first: write the point in one plain sentence. If you cannot, the draft has no point yet.
2. Cut: throat-clearing openers, summaries, "in conclusion", repeated points.
3. Concrete: replace each abstraction with the thing (the jar, the rubber band marking the rise, the loaf that spread flat).
4. Voice: swap in the creator's words; match their sentence length and punctuation from their samples.
5. Rhythm: read it aloud (it is Instagram; it may be spoken). Vary length. End on the strong word.

## Pattern fixes

| pattern | example | fix |
| --- | --- | --- |
| Not X, but Y | "It's not just bread, it's a lifestyle." | "It's the loaf you bake on Tuesdays." |
| Announcing | "Here's the thing:" / "Let's dive in" | Delete; start with the thing. |
| Rhetorical Q + answer | "The result? Better bread." | "My loaves stopped spreading." (if true) |
| Triads everywhere | "faster, simpler and more profitable" | Keep the one that matters. |
| Hedge stack | "might perhaps help you potentially" | "helps" or cut the claim. |
| Stock openers | "In today's fast-paced world" | Delete. |
| Abstract nouns | "transformation", "journey", "landscape" | Name what changed, where, for whom. |
| Uniform rhythm | 5 sentences of 18-20 words | One 4-word sentence; one 25-word sentence. |
| Clause dashes | "the starter — the real problem — is..." | Full stops or commas. |
| Same openers | "You... You... You..." | Rotate subject: I / the dough / this / it. |

## Voice matching

- Steal sentence shapes from `voice.sample_texts`: how long, how they start, how they end.
- Use `words_i_use` where natural; never use `words_i_never_use`.
- Match energy: a dry, calm creator does not suddenly write "This is HUGE!!!".
- Contractions if their samples use them.
- Keep their quirks (a recurring phrase, a sign-off) unless they hurt clarity.

## What not to change

- Facts, numbers, names, quotes, {{placeholders}}, legal disclaimers.
- Keywords the caption needs for search.
- The CTA keyword (spelling and case).

## Honesty line

The goal is writing that is specific, plain and recognisably the creator's.
Do not promise that it will pass any AI detector. If asked, say what the report
measures and that no tool can guarantee a detector's verdict.
