# Carousel types

| type | slide plan | best for | design note |
| --- | --- | --- | --- |
| Steps | cover → why → step 1..n → common mistake → recap → CTA | processes, how-tos | big step numbers, one action per slide |
| Mistakes | cover → mistake 1..n (each: mistake, cost, fix) → CTA | saves | red/green or ✗/✓ markers, same layout each slide |
| Myth / truth | cover → myth → truth → evidence → what to do → CTA | contrarian takes | myth slide visually "crossed out" |
| Framework | cover → the model (diagram) → part 1..n → example → CTA | positioning, authority | one diagram reused with the active part highlighted |
| Before / after | cover (the after) → before → change 1..n → after → CTA | portfolios, rewrites | real artefacts, annotated |
| Case study | cover (the result, verified) → situation → problem → what we did → result → lesson → CTA | proof (verified only) | screenshots with client details removed, with permission |
| Story | cover (mid-scene) → setup → turn → what I did → what changed → lesson → CTA | relatability | photo-led, short captions per slide |
| Comparison | cover (A vs B) → criteria 1..n with verdicts → when to pick each → CTA | decisions | two-column layout, consistent colours for A and B |

## Continuity devices

- Numbered sequence ("1/5") the viewer wants to finish.
- Open loop at the bottom of a slide ("The fix is on the next slide").
- Visual thread: a recurring element that changes state slide by slide.
- Question on slide n, answer on n+1.

## Cover rules

- ≤ 10 words, one idea, readable at thumbnail size.
- Promise a specific outcome or name a specific mistake.
- Contrast: the headline is the largest, highest-contrast thing on the slide.
- Keep it inside the centre 3:4 area so the grid crop does not cut it.

## Type sizes at 1080 px wide

- Cover headline 90-120 px. Slide headline 70-90 px. Body 38-48 px. Never below 32 px.
