# Format mapping

| source shape | becomes | notes |
| --- | --- | --- |
| A story with a turn | reel (story structure) | Start mid-scene; the lesson as the CTA lead-in. |
| A strong opinion | reel (myth -> fix) or quote reel | One claim per reel. |
| Steps / a process | carousel (steps) | One step per slide; source order preserved. |
| A framework / model | carousel (framework) + reel teaser | Diagram on the carousel; reel names the model and the payoff. |
| A list of mistakes / tips | carousel (mistakes) or numbered reel | Keep the 3 strongest. |
| A surprising number (spoken) | reel hook or carousel cover | Same wording as the source; confirm with the creator. |
| Q&A segment | reply reel or story question follow-up | Quote the question. |
| A demo or screen share | reel (tutorial) | Clip it if the original footage is usable. |
| An analogy | single image or reel | Analogies travel well alone. |

## Fidelity rules

1. Quotes are verbatim. Trimming filler words ("um", "you know") is fine; changing words is not.
2. Paraphrases keep the claim's strength: "often" stays "often", not "always".
3. Numbers and names exactly as in the source; the creator confirms before they go in `verified_facts`.
4. Context the clip needs must be inside the clip or added as on-screen text ("On why I stopped quoting on calls:").
5. Guests' words are attributed to guests and used only with their OK.
6. Every piece carries its source timestamps in the handoff so the creator can check it.

## Standalone test

Read the piece as someone who never saw the source. If any sentence needs the
original to make sense, rewrite it or add the missing line.
