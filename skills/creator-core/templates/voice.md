# voice.md

Optional companion to `profile.json` (same folder, default `~/.creator-content-kit/`).
`profile.json > voice` holds the short, structured version that the tools check
against; this file holds the nuance the agent reads before drafting.

You don't have to fill it in by hand. Paste a handful of your real captions or
reel transcripts into the chat and ask the agent to draft this file from them,
then correct whatever it gets wrong. Real samples tell it more than adjectives do.
