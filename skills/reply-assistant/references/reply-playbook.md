# Reply playbook

| category | goal | reply shape | example |
| --- | --- | --- | --- |
| lead | start a private conversation | acknowledge + where the answer is + DM | "Good question, it depends on what you want to bake. Sent you a DM." |
| support | fix it fast, privately | apologise once + action + DM | "Sorry about that, sending it in DMs now." |
| keyword | deliver what was promised | confirm + delivery channel | "Sent!" (after the DM goes out) |
| question | answer in public (others have it too) | direct answer in 1-2 sentences | "Yes, same idea in a cold kitchen, just give it an extra few hours." |
| pushback | be useful once | concede what's fair + the distinction + stop | "Fair on rye. It ferments faster; this was about wheat starters." |
| story | relationship | react to their detail + small question | "The one-flat-day panic is so common. Did it come back after a feed?" |
| praise | warmth, brief | specific thanks | "Glad the morning-feed bit helped." |
| tag | none needed | like | |
| general | optional | like, or one line if there's something to say | |
| spam | protect the thread | hide / delete / restrict; never reply | |

## Rules

- Reply as the creator, in their voice; never sign as an assistant.
- No new claims. If a reply needs a number, it comes from the profile or it waits for the creator.
- One reply per comment. No threads with trolls.
- Questions that repeat 3+ times are content: suggest a reply reel.
- Do not ask people to "check DMs" without actually sending the DM.
