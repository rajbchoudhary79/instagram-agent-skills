# Story sequence patterns

Frame counts are typical; story.py checks the funnel, not the count.

## 1. Daily connect (4-5 frames)
hook (what's happening today) → context (a photo/clip) → interact (slider or poll about it) → value (one small tip) → close (question sticker)

## 2. Promote today's post (3-4 frames)
hook (tease the problem the post solves) → interact (poll: "Do you do X?") → value (one slide/clip from the post) → convert ("New post: tap to watch" with the post shared)

## 3. Teach with a quiz (5-6 frames)
hook (the question) → interact (quiz with the common wrong answer as an option) → value (the answer, why) → value (example) → interact (slider: "how useful?") → close (question box for follow-ups)

## 4. Collect objections (3-4 frames)
hook ("Honest question...") → interact (question sticker with a specific prompt) → close (when you will answer). Next day: answer the best 3 on screen, link the top one to a reel.

## 5. Keyword DM funnel (5-6 frames)
hook (a problem the freebie solves) → interact (poll: do you struggle with this?) → value (one useful part of the freebie) → proof (verified result or a screenshot with permission) → convert ("DM me WORD and I'll send it") → close
The DM reply is written with dm-assistant; automation only through official tools and only for people who messaged.

## 6. Launch warm-up (over 3-5 days)
Day -3: behind the scenes + poll on a feature. Day -2: the problem story + question box. Day -1: countdown (real date) + FAQ answers. Launch day: hook → what it is → who it is for → proof (verified) → link → close. After: answer questions, share real feedback with permission.

## 7. Behind the scenes (4-6 frames)
hook (where I am / what I'm making) → process clips (2-3) → interact (slider or "which version?" poll) → close (what's coming)

## 8. Community spotlight (3-4 frames)
hook → reshare (with permission) of an audience member's story / win → interact (add-yours prompt) → close

## Rules of thumb

- First frame decides whether people tap through. Faces and specific claims hold.
- Text frames: one idea, big type, ≤ 20 words.
- Results from polls are content: share them the next day.
- Never fake urgency ("only 3 spots") unless it is true and verifiable.
